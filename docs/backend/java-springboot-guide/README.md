# Java 与 Spring Boot 新手入门指南

这套文档面向没有 Java 后端经验的学习者。目标不是一次记住所有语法，而是先建立完整认知，再通过一个小项目把 Java、Spring Boot、数据库和接口开发串起来。

## 建议环境

- JDK：Java 21 LTS（最低建议 Java 17）
- IDE：IntelliJ IDEA Community / Ultimate
- 构建工具：Maven 3.9+
- Spring Boot：3.x
- 数据库：MySQL 8.x；入门阶段也可以先使用 H2
- 接口测试：IDE HTTP Client、Postman 或 Apifox

> Spring Boot 3.x 要求使用 Java 17 或更高版本，代码中的 Web 包名使用 `jakarta.*`，不要照搬旧教程中的 `javax.*`。

## 推荐学习方法

每学习一个知识点，都完成下面四步：

1. 用自己的话解释它解决了什么问题。
2. 手动输入示例代码，不要只复制粘贴。
3. 修改参数或故意制造错误，观察编译器和日志。
4. 写一个比示例稍微复杂的练习。

建议每天保持 1～2 小时：

```text
20 分钟：阅读概念
40 分钟：手写示例
30 分钟：独立练习
10 分钟：记录问题和总结
```

## 学完后的自测标准

- 能解释 JDK、JRE、JVM 的关系。
- 能使用类、接口、集合、异常和泛型编写小程序。
- 能看懂 Maven 项目结构和 `pom.xml`。
- 能解释 Spring 的 IoC 和依赖注入。
- 能用 Spring Boot 编写 RESTful CRUD 接口。
- 能使用参数校验、统一异常处理和配置文件。
- 能把数据保存到 MySQL，并理解事务的基本作用。
- 能独立定位端口占用、Bean 注入失败、SQL 错误等常见问题。

## 不建议一开始就学的内容

微服务、分布式事务、Spring Cloud、消息队列、Kubernetes 和复杂设计模式都很重要，但不适合作为第一阶段主线。先完成一个结构清晰、能测试、能连接数据库的单体应用，再逐步扩展。
